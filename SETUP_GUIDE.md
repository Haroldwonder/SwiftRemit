# Setup Guide

## Node.js version

This repository uses **Node.js 20** (see `.nvmrc` and `.github/actions/setup-node/action.yml`). From the repository root, run `nvm use` before running npm commands. The root `package.json` accepts Node.js `>=20.0.0`.

The canonical setup guide is now in [docs/SETUP_GUIDE.md](docs/SETUP_GUIDE.md).
